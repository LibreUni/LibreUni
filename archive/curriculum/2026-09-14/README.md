# Retired curriculum source

These files were moved intact out of the active content collections on 2026-09-14 when the project chose Computer Architecture, Operating Systems, and Database Systems as its reference curriculum. The seven retired courses, their manifests, and the three former paths include the uncommitted state at the time of retirement; Git history alone would not preserve that work.

This is a recovery archive, not an alternative catalog. Astro, search, course books, and active-course checks must not load it. Relative component imports intentionally retain their original locations; archived MDX is not independently buildable here.

To recover material, review the specific lesson against the current course standard, move its source back to the appropriate `src/content` location, restore its manifest and metadata, and run the content/build/browser gates. Do not restore a whole course merely because it once passed a structural check. The former paths depended on retired courses and must not be re-published without redesign.
