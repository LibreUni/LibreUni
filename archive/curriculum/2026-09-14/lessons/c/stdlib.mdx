# The C Standard Library as a Contract

The standard library is portable only when its preconditions are respected. A function name such as `qsort` or `strtol` hides a protocol: element size, callback ordering, buffer extent, locale, conversion range, or termination behavior. Read the signature together with its documentation.

## Sorting and searching

`qsort` receives a base pointer, element count, element size, and comparator. A safe integer comparator is:

```c
int compare_ints(const void *left, const void *right) {
    int a = *(const int *)left;
    int b = *(const int *)right;
    return (a > b) - (a < b);
}
```

`bsearch` requires the array already be sorted under a compatible comparator. Its result is a pointer into the caller's array, not an owned copy; its lifetime ends when the array is modified or destroyed.

## Numeric conversion

`atoi` cannot report malformed input or range failure. `strtol`/`strtoul` return a converted value and an end pointer; set `errno = 0`, check that at least one digit was consumed, and check `errno == ERANGE` and the target type's bounds before narrowing.

## Termination and randomness

`exit` runs registered exit handlers and flushes standard streams; `abort` signals abnormal termination and is not a cleanup strategy. `atexit` callbacks should be small and must not assume resources that have already been destroyed. `rand` is a portable pseudo-random generator with weak and implementation-dependent statistical/security properties; never use it for keys, tokens, or passwords.

### Diagnostic solutions

1. Initialize `end = input`, call `strtol`, and reject when `end == input`; also check range and trailing characters according to the grammar.
2. Sorting requires an equivalence relation; if equal elements compare as unequal, the comparator can be inconsistent and violate the ordering qsort relies on.
3. It designates an element in the original array. It is borrowed and becomes invalid when that storage ceases to be valid or a modifying operation invalidates the reference.
4. The generator is predictable if its state is known, and modulo can bias outcomes unless the range is handled carefully. Security requires an OS or library CSPRNG.
