# Strings, Encodings, and Buffer Contracts

C has no built-in string object. A C string is a contiguous sequence of characters terminated by a zero-valued byte. A character array may contain no terminator, and a byte buffer may contain arbitrary zero bytes; treating either as a string without a proof is a boundary error.

## Literals and writable arrays

```c
const char *literal = "hello"; /* points at a string literal */
char copy[] = "hello";         /* six writable char objects */
```

Modifying a string literal has undefined behavior. The `const` qualifier communicates the safe access contract even though old C types permit some literal forms to be assigned to `char *`. Use a writable array or allocated storage when mutation is required.

## Capacity-aware operations

`strlen` scans until a terminator and is safe only when its argument is a valid C string. `strcmp` returns zero for equality; a nonzero result is not a Boolean “true means equal”. `strcpy`, `strcat`, and similar functions require the caller to prove destination capacity before the call; their names do not perform a bounds check.

For formatted output, `snprintf(destination, capacity, "%s", source)` writes at most `capacity` bytes including a terminator when `capacity > 0`. Its return value reports the length that would have been produced, so a return value at least `capacity` indicates truncation. Treat truncation as a policy decision, not as silent success.

## Input and encoding boundaries

`fgets` accepts a capacity and retains a newline when one fits; callers must decide whether to strip it. A UTF-8 string is still a sequence of bytes to the C library unless a higher-level library interprets code points. `strlen` counts bytes, not user-perceived characters. Never split a multibyte encoding or normalize untrusted text by accident.

## Transfer exercises

1. Explain why `char bytes[4] = {'A', 'B', 'C', 0};` is a string but `char bytes[3] = {'A', 'B', 'C'};` is not.
2. Specify the postcondition of a function that truncates a string into a destination buffer.
3. Give two independent checks needed before calling `strlen(p)`.
4. Explain why `strncpy` is not a complete safety policy.

### Diagnostic solutions

1. The first array has a zero terminator; the second has no terminator within its extent, so scanning it may read beyond the object.
2. State that the destination is terminated when capacity is positive, contains the longest prefix that fits, and reports whether the source was truncated. Define behavior for capacity zero.
3. `p` must be non-null or otherwise a valid pointer, and it must designate a live array containing a zero byte within its accessible extent.
4. It may leave a destination unterminated when the source fills the bound, pads the entire destination unnecessarily, and still requires the caller to reason about overlap and source validity.
