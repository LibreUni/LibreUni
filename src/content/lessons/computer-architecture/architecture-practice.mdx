## Problem Workshop

This workshop generates algorithmic practice problems spanning computer architecture: signed two's complement representation, pipelined data hazards and forwarding, multi-level cache AMAT calculations, and branch misprediction penalties.

### Recommended Workflow

1. Calculate cycle counts, bit decompositions, and memory access times independently before inspecting hints.
2. Consult progressive hints when encountering pipeline dependencies or hierarchy parameters.
3. Verify derivations against the complete worked solution, checking hardware state transitions and penalty cycles.
