## Problem Workshop

This workshop generates algorithmic practice problems spanning database systems: relational algebra operations, functional dependency closures and normal forms, query optimization cost models, transaction conflict serializability, and ARIES crash recovery analysis.

### Recommended Workflow

1. Derive complete query plans, attribute closures, and recovery states independently before inspecting hints.
2. Consult progressive hints when reaching a modeling or algorithmic impasse.
3. Verify derivations against the complete worked solution, checking invariant conditions and state transitions.
