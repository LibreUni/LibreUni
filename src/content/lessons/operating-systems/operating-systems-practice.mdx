## Problem Workshop

This workshop generates algorithmic practice problems spanning operating systems: Round-Robin scheduling timelines, multi-level page table index decomposition, inode capacity arithmetic, and Amdahl multicore scalability limits.

### Recommended Workflow

1. Derive scheduling Gantt charts, virtual address bit-slices, and storage capacities independently before inspecting hints.
2. Consult progressive hints when reaching an address translation or scheduling impasse.
3. Verify derivations against the complete worked solution, checking boundary invariants and state transitions.
